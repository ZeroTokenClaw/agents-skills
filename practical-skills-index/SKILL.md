## 快捷路由

1. 网页/UI → `product-dev-skills` → `frontend-design`
2. 产品文档 → `prd-development` / `user-story`
3. React 性能 → `vercel-react-best-practices`
4. 算法题 → `leetcode-teacher`
5. E2E → `playwright-testing` 或 `webapp-testing`
6. 计算/表格 → `calc-analysis-skills`
7. 做 PPT → `pptx`
8. 宇树 / 导览+签到+跟随 → `tour-checkin-follow` 或 `unitree-embodied-skills`
9. 仅跟随 → `robot-person-follow`；仅签到 → `face-checkin-robot`
10. LangGraph / 计划模式 / 子代理 → `langgraph-coding-agent`
11. 内容/短视频/电商/配音 → `anbeime-skills-index`
12. 大位移光流 / MegaFlow 点跟踪 → `megaflow`
13. 专利交底/权利要求 → `patent-drafting`

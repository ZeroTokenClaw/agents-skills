# 软著申请表字段对照

| 字段 | 填写要点 | 本软件取值 |
| --- | --- | --- |
| 软件全称 | 中文为主，反映功能 | |
| 软件简称 | 可空 | |
| 版本号 | 如 V1.0，与材料一致 | |
| 软件分类 | 按系统选项 | |
| 开发完成日期 | ≥ 实际可运行日；勿作假 | |
| 首次发表日期 | 未发表则按系统选项 | |
| 发表地点 | 按实际 | |
| 权利取得方式 | 原始取得 / 继受取得 | |
| 权利范围 | 全部权利 / 部分权利 | |
| 软件说明（简述） | 功能、领域、特点，客观 | |
| 硬件环境 | CPU/内存/设备等 | |
| 软件环境 | OS、运行时、中间件 | |
| 编程语言 | 与源码一致 | |
| 源程序量 | 行数（约） | |
| 开发目的 | 一句话 | |
| 面向领域/行业 | | |
| 主要功能 | 分条 | |
| 技术特点 | 分条 | |
| 申请人类型 | 自然人/企业/机关等 | |
| 申请人名称 | 与证件一致 | |
| 开发方式 | 独立/合作/委托/下达任务等 | |

## 开发方式附件提示

| 方式 | 常备材料 |
| --- | --- |
| 独立开发（企业） | 营业执照；可附职务开发说明 |
| 合作开发 | 合作协议、权利约定 |
| 委托开发 | 委托合同、权利归属条款 |
| 继受取得 | 转让合同、原登记证明等 |

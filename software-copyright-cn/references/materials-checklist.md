# 软著鉴别材料与形式要求（实务备忘）

> 中国版权保护中心要求可能调整；提交前与官方通知或代理核对。

## 源程序

| 项 | 常见要求 |
| --- | --- |
| 页数 | 前 30 页 + 后 30 页；不足 60 页交全文 |
| 每页行数 | ≥ 50 行（最后一页可不足） |
| 连续性 | 前 30 页为开头连续页；后 30 页为结尾连续页 |
| 页眉 | 软件全称 + 版本号 |
| 页脚 | 页码 |
| 内容 | 实际参与编译/解释的源码；避免大段无意义重复 |

## 文档（说明书）

| 项 | 常见要求 |
| --- | --- |
| 页数 | 前 30 + 后 30 或全文（页数不足时） |
| 内容 | 能体现软件功能与操作，与申请软件一致 |
| 图文 | 可含界面截图；注意脱敏 |

## 装订与签章

- 按当前登记指南：封面、目录、装订位置、签章页
- 申请表签章与主体证件一致（公章/签字）

## 提交前脱敏

- [ ] API Key / Token / 私钥  
- [ ] 数据库连接串、内网地址  
- [ ] 真实用户姓名/手机号/身份证  
- [ ] 未授权的第三方商标素材（说明书截图）

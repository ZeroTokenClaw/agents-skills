# 权利要求书骨架（发明/实用新型）

## 写作规则

1. 以「一种…」开头；结尾用句号。
2. 独权写**必要技术特征**；效果性语言放到说明书。
3. 从权引用格式：`根据权利要求X所述的…，其特征在于…`
4. 同一概念全文同一用语。
5. 方法权利要求用步骤；装置用结构/连接关系或“模块+功能”需能落到结构或程序模块。

---

## 示例骨架 A：方法

```text
1. 一种……方法，其特征在于，包括：
   步骤S1：……；
   步骤S2：……；
   步骤S3：……。

2. 根据权利要求1所述的方法，其特征在于，所述步骤S2包括：
   ……。

3. 根据权利要求1或2所述的方法，其特征在于，……参数满足……。
```

## 示例骨架 B：装置/系统

```text
1. 一种……装置，其特征在于，包括：
   ……模块，用于……；
   ……模块，用于……；
   其中，……模块与……模块连接，并用于……。

2. 根据权利要求1所述的装置，其特征在于，所述……模块包括……。
```

## 示例骨架 C：存储介质 / 设备（可与方法配套）

```text
1. 一种计算机可读存储介质，其上存储有计算机程序，其特征在于，
   所述程序被处理器执行时实现权利要求X–Y任一项所述方法的步骤。

2. 一种电子设备，包括存储器与处理器，其特征在于，
   所述存储器存储程序，所述处理器执行所述程序时实现权利要求X所述方法。
```
